# Python Practice and Study Progress Tracker

This repository contains Python exercises and projects I built while learning Python.

## Featured Project: Study Progress Tracker

A command-line application designed to help students organize tasks and track their study progress.

### Features

- Create tasks with subjects, deadlines, priorities, and recurring schedules
- Run timed study sessions and record study duration
- Receive reminders for approaching deadlines
- Delete tasks and undo the most recent deletion
- View task completion statistics and study time by subject
- Track study streaks and unlock achievements
- Search tasks and view a study leaderboard
- Store task and user data in JSON files

### Concepts Practised

- Python classes and object-oriented programming
- Functions, lists, dictionaries, and stacks
- File handling and JSON serialization
- Date and time handling
- Exception handling and input validation
- Threads and basic program design
